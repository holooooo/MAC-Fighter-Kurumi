## 借鉴的交互原则

- 上游 `src/shared/physics.ts` 将拖动、松手判定与有限时 squash/stretch 分开；韭留美使用 AppKit 原生事件实现自身的 4pt 拖动阈值和工作区约束，不让短点击误变窗口位移，不使用全局鼠标监听抢占其他应用。
- 上游 `src/shared/pickers.ts` 的动作池避免连续重复；韭留美当前按 `assets/kurumi-generated.json` version 2播放用户选定JPEG人设的15个GIF，不再以SVG头部/手臂/眼睛分组动画作为生产角色。6个为原图本地仿射变换、9个来自3条已完成生成视频的本地剪辑与重定时。人设保持节点 `A4vCOxNi9Wh_dGLJr7B8rb` 的实际比例、白裙、酒红蝴蝶结与鞋，不按历史标题强制二头身。待机候选不连续重复，空闲6–12秒后再抽取有限时动作，不做永久60fps脚本轮询。
- 上游渲染端用明确事件结束/中断管理播放；韭留美把交易动作、互动和待机分层：交易可中断游戏动作，拖动开始清理旧动画，隐藏和减少动态设置清理定时器，松手不冒充买卖信号。

## 共享文字与图片气泡

`pet-speech.js` 提供文字/图片共享气泡，`pet-ui.js` 负责事件接入。借鉴的是上游明确生命周期、事件优先级和内容呈现的通用思路，不复制其受限动画、提示词、源视频或表情包。

- 文字按长度展示6–10秒；通常以250ms退出过渡收起，减少动态时直接收起。文字与图片使用同一条消息和生命周期，不另开竞争计时器。
- 优先级阻止低优先级内容覆盖当前高优先级消息；相同事件ID去重，异步图片仅能附加到仍匹配的消息token，不能覆盖后来的消息。
- 自动表情图片仅对符合条件的事件按20%概率尝试，至少间隔12秒，使用本地已有图库，不调用生成接口、不自动外发。
- 页面隐藏、原生不可见或销毁时停止呈现并清理计时器；打开手动表情包层时暂时遮盖气泡并保留剩余展示时间，关闭后继续。

## 交易日记边界

日记基于服务端真实成交持久化，最多保留最近500笔，显示截断与部分历史标记；不是浏览器localStorage，也不补造旧档缺失成交。前端只读模块正在集成，不能将模块存在等同于最终界面、回归及打包完成；最终测试数量由Lead执行后填写。

## 原生与页面协议

只信任本地页面既有受限桥接；这些事件不调用资金接口：

- `jiuliu-pet-tap`：短点击互动，不等同于买入。
- `jiuliu-pet-drag`，detail `{phase:'start'|'end'}`：悬空/落地反馈。
- `jiuliu-pet-action`，detail `{name:'wave'|'stretch'|'sleep'|'meme'}`：由原生右键菜单点播；表情包只打开选择，不自动外发。

目前没有移植惯性甩抛、宠物碰撞、屏幕漫游、多宠物系统或透明视频双播放器。先保证现有角色拖得动、点了有明确反馈，保持轻量与隐藏停止。
