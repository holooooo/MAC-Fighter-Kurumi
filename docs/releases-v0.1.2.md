# 韭留美 v0.1.2

## 更新

- 新增由现有透明角色素材设计的 macOS 应用图标，应用包内有 `CFBundleIconFile` 指向的原生 `.icns`；没有获取新的收费生成素材。
- 透明桌宠窗口保留可拖动的顶部区域，但移除了红色拖动指示线和『打开面板』浮动入口；主面板仍可从菜单栏打开。
- 角色裙装前实时展示当前账户的收益率及近 32 个真实记录点的迷你曲线；起始资金为零改显示权益；没有记录时不伪造曲线，旧报价标记『旧』与虚线。
- 新的买入、卖出、卖空、买回和强平事件由桌宠气泡直接播报品种与数量，开仓有多倍杠杆时同时说明倍数；不再显示『最近一单』卡片，也不会重播已有历史记录。
- 面板新增自动交易冷却选项：T+1 分钟（新账户默认）、T+1 小时、T+1 天（24 小时），也可关闭。它阻止冷却期内下一笔自主交易；手动平仓和风险强平不受阻。设置与上一笔自主成交时间随本地账户持久化。
- 新开立的虚拟账户偏激进：默认 10× 杠杆、约 95% 可用现金作保证金、资金不足且有真实交易信号时允许间隔至少 60 秒自主申请虚拟贷款；不操作真实资金。**现有账户的已保存性格、杠杆、自动投资和借款选择保持不变**，原有账户首次升级时只补充 T+1 分钟冷却。可在面板随时关闭自动借款、调低杠杆或暂停自动交易。
- 杠杆选择与服务默认值打通，手动和自主开仓使用同一设置；旧账户会显示自身存档中的杠杆，而非硬编码 10×。
- 宿主检查本地服务协议版本，不再静默复用旧版服务导致冷却选项失效；旧服务仍需由用户确认后正常退出，应用不会擅自终止其他进程。
- 修复退役旧指标的空仓迁移估值，保证金、已实现方向差价与利息按空仓口径结算，保持迁移前后权益一致。

## 核验与边界

- 源码完整 Node 测试、纯 Swift 测试、原生主窗／桌宠启动烟雾测试通过。正式 ZIP 由 GitHub Actions 在 `macos-15` arm64 环境构建，内含官方 Node.js 24 arm64 运行时和 Widget 扩展，使用 ad-hoc 签名，**未进行 Developer ID 签名或公证**。
- 行情是电脑实际采样映射为虚拟商品的游戏；高杠杆和虚拟贷款会快速放大波动，收益数字不是实际投资回报。冷却保护不阻止系统强平。
- 最新三条额外梗动画此前首个收费任务因配额不足失败、产物 0 且余额未减少；其余未提交，因此本版继续采用现有 15 个透明 APNG 动作。Widget 图库添加及部分物理拖拽尚未完成实际设备手工验收。

## 下载与安装

从此版本 GitHub Release 下载 `JiuliuPet-v0.1.2-macos-arm64.zip` 和 `SHA256SUMS`，放在同一目录执行 `shasum -a 256 -c SHA256SUMS`；显示 `OK` 后解压并将 `韭留美.app` 拖入『应用程序』。Apple Silicon Mac，建议 macOS 14+；首次打开、权限、旧账户备份、端口冲突与升级步骤详见仓库的 `docs/installation.md`。不要关闭全局系统安全检查。
