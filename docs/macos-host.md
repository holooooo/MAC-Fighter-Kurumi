# macOS 宿主验收与运行

宿主使用 AppKit + WKWebView 复用实时交易界面，桌宠为独立透明 NSPanel。不是 Electron，不依赖用户另外安装 Node（打包包含运行时）。目前为本机开发构建和 ad-hoc 签名，未公证，不代表可直接向所有 Mac 分发。

## 构建

```bash
bash scripts/build-macos.sh
open output/韭留美.app
```

要求 macOS 13+、Swift Command Line Tools、可独立分发的 Node。脚本会检查 Node 的动态库依赖；若依赖 Homebrew 库则拒绝打包，使用 KURUMI_NODE_PATH 指向官方独立运行时。编译架构以当前 Swift 工具链为准。

## 使用

主窗口显示真实系统采样和虚拟交易面板；桌宠窗口透明置顶，跨桌面显示，可拖动角色身体或顶部小横条，短点击身体触发互动。上方打开面板、下方表情按钮与表情弹层不属于拖动命中区。位置和显隐偏好在普通退出时保存，恢复或拔除显示器时限制到当前屏幕可见区域；smoke 不读取或污染这些偏好。菜单栏「韭留美」可打开面板、显示/隐藏桌宠、退出。关闭面板不退出采集服务和桌宠，也不会停止已有虚拟债务计息。

应用先探测 127.0.0.1:8766 的实时服务。若已有合适服务，直接复用，退出时不结束它。若没有则从应用资源启动自己的 Node 子进程，退出时发送 SIGINT 保存存档。固定端口若被其他程序占用，会显示错误，不杀占用进程。

桌宠页为 `/pet.html?desktop=1`，透明背景，显示角色、语录、打开面板与表情入口，不创建 K 线或加载图表库。前台每两秒读取服务事件，隐藏时停止页面轮询和闲聊动画；主面板与后台服务继续各自运行。外链由用户点击后交给默认浏览器。原生「发送」仅打开系统分享选择器，发送目标与后续动作由用户确认，不自动发送。

## 图表、估值和虚拟财务

主面板使用本地 MIT Chart.js 4.4.8 + chartjs-chart-financial 0.2.1、Luxon 3.6.0 和 chartjs-adapter-luxon 1.3.1，保留原许可证。锁定文件、来源及哈希见[图表依赖清单](../vendor/chart-dependencies.json)。当前不是 TradingView／Lightweight Charts 渲染，不通过隐藏品牌处理许可要求，也无需运行时 CDN。

图表提供分钟、小时、日三档K线，由真实采样聚合完整OHLC；全部盘口、主图与账户图共享平移/缩放窗口。断采和离线时不补点、不插值。债务不是收入：净权益包含现金与多空持仓净权益并扣除借款，收益相对本局初始资金计算，过期持仓价格估值明确标 stale。

游戏无限授信仅表示累计无固定玩法额度，每笔个人借款 10 万–300 万虚拟币，仍受数值安全边界约束。虚拟个人破产会清空现金／仓位／债务、将 initialCash 设为 0 并暂停自动投资；保留 bankruptcyLedger 和上一局收益摘要，以新 episode 开始，债务豁免不算盈利。这里没有真实借款、信用记录或法律破产效果。计息、跨局历史与大负数边界见[虚拟金融玩法](finance-gameplay.md)。

## 自动验收

```bash
output/韭留美.app/Contents/MacOS/JiuliuPet --smoke-test
```

该模式在真实WKWebView里检查主面板和桌宠DOM、在线品种、SVG加载、图表库是否按模式加载及原生视图尺寸，输出JSON后退出。失败返回非零退出码；它不是逐帧美术验收的替代。若复用了已有服务，检查退出不会关闭它。

## 验收重点

- `.app` 能启动且角色透明，不出现整个交易页面塞进桌宠窗口。
- 主面板和桌宠看到同一账户/语录，打开面板入口不破坏小窗口。
- 角色可拖动、置顶，可通过菜单隐藏和恢复。
- 已有服务被复用；应用退出后原有服务仍可访问。
- 自启服务在退出时保存，重新打开能恢复账户且不伪造离线K线。

## 原生外设采集

应用服务就绪后开始采集，退出时取消定时器、事件 tap 及网络请求。当前采集移动距离率 `MOUSE_DISTANCE`、鼠标点击率 `MOUSE_CLICKS` 和键盘计数率 `KEYBOARD`，不再采集旧鼠标频率和电量。移动通过只监听移动／拖动的 CGEvent tap 累积 delta 长度；点击与键盘读取 CoreGraphics 计数差，以真实经过时间换算每秒速率。键盘计数包含重复 keyDown，但不读取键值或文本。

需要系统已授予相应输入监控能力，本应用只 preflight，不主动弹出授权请求。无权上报 permission-required，不把缺失数据变成 0；首个区间只建基线，唤醒长间隔和计数重置不补造数据。网络载荷仅含指标 id／值／时间或不可用原因，不含设备身份、坐标轨迹或按键内容。这些是实际实现边界，不等于每台机器已完成权限与实测验收；详见[外设说明](peripherals.md)。

真正的WidgetKit扩展已构建并嵌入，系统pluginkit已发现；图库添加与实际渲染尚待验证，详见[小组件说明](widget.md)。透明桌宠窗口与系统小组件是独立实现。
